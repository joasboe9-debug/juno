# Juno

Juno is a simple AI website prototype with two tabs:

- Chat tab: Juno Core v0.1
- Experiments tab: Juno Imagine v0.1

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple local server:

```bash
cd juno
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- Juno Core is a lightweight conversational assistant mock.
- Juno Imagine generates simple pixel-art scenes using original, royalty-free-style sprite tiles created for the prototype.
- This is a front-end prototype and is meant to be expanded with a real API backend later.
